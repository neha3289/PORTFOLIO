NEHA BIJU — PERSONAL PORTFOLIO
================================

HOW TO RUN
1. Extract neha-portfolio.zip.
2. Open the folder in Visual Studio Code, or double-click index.html.
3. For a better development workflow, open index.html using the VS Code Live Server extension.

FILES
- index.html : portfolio structure and content
- style.css  : colors, layout, responsive design, animations, dark theme styles
- script.js  : light/dark toggle and current year

CUSTOMIZE BEFORE PUBLISHING
- Replace https://github.com/ with your GitHub profile URL.
- Replace https://www.linkedin.com/ with your LinkedIn profile URL.
- Replace your-email@example.com with your professional email address.
- Add your résumé PDF as assets/Neha-Biju-Resume.pdf.
- Update the college details and project descriptions to reflect your actual work.

NOTE
The Financial Dashboard is presented as a starter project idea, not as a completed project.
